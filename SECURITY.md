# Security Policy

## Supported Versions

Only the latest version on the `main` branch receives security fixes.

| Version | Supported |
| ------- | --------- |
| main    | Yes       |
| older   | No        |

## Reporting a Vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately in one of these ways:

1. Use GitHub's private reporting: go to the **Security** tab of this
   repository and click **Report a vulnerability**.
2. Or email me at YOUR_EMAIL_HERE.

Please include:
- A description of the problem and where it is
- Steps to reproduce it
- The impact you think it has

## What to Expect

- I will acknowledge your report within 14 days.
- I will keep you updated while I work on a fix.
- Once the fix is released, I will credit you if you'd like.
